使用说明 当前 v3.04.03
一页看完：本工具只给文件名加色彩标记，所有处理都在本机完成。以下 9 节覆盖声明、来源、上手、常见问题与许可证。
使用顺序：① 选择分析范围›② 分析›③ 标记›④ 选择改名范围›⑤ 按标记改名

① 做什么 / 不做什么

  • 只修改文件名，不影响辨认度：把文件名末尾的色彩标记改成 _D1/_D2/_DH/_DN/_DM/_DC/_DU；只改目录项，撤销依赖最近一次改名记录。
  • 不上网：服务只监听 127.0.0.1，页面只请求本地 /api；软件运行不联网。
  • 不改素材内容：识别全程只读；抽帧在内存管道完成，不落盘中间文件、不写回源视频。
  • ffmpeg 只用于对比度 / 饱和度分析：仅主动触发分析时调用本地 ffmpeg，不转码 / 裁剪 / 合并 / 导出。
  • GitHub 链接仅用户主动点击才跳转，软件运行不联网。

② 识别来源与优先级

  • ① 机身元数据：MP4 moov/meta 的 ColorGammaSxS（Osmo Pocket 4P，最可靠）；
  • ② 同名 .SRT 字幕的 color_md（Avata 360 / Avata 2 / O4 Air Unit Pro / O3 天空端，需录制前开「视频字幕」）；
  • ③ 无色彩元数据：Osmo Pocket 3 / Action 2 / Osmo Nano / Osmo 360 II，需手动指定或画面参考；
  • ④ 都没有 → 标「未知」(_DU)。
  • 「设备」列来自文件内 ©too 元数据；O3 天空端未写型号，显示「— 未记录」。

③ 文件名标记对照

  • D-Log → _D1　D-Log 2 → _D2　HLG → _DH
  • 普通 Rec.709 / Normal → _DN　D-Log M → _DM
  • D-Cinelike → _DC　未知 → _DU
  • DJI_xxxx.MP4（O3 / Action 2，无 _D 标记）是追加后缀：DJI_0006.MP4 → DJI_0006_DN.MP4；同名 .LRF/.SRT 等配套文件同步。已正确标记时保持原样，不会出现 _D11。

④ 三步上手

  • 1. 选目录并扫描：粘贴文件夹路径，或用「浏览文件夹…」（内置浏览器）/「系统对话框」，点「扫描」。
  • 2. 核对结果：看「识别结果 / 来源」与「标记为」；识别不出时用批量指定下拉手动选，或勾选「分析」列跑画面参考。
  • 3. 执行改名：确认「改名」勾选范围后点「执行重命名」；改错了可用「撤销重命名」按勾选范围撤回。

⑤ 表格列说明

  • 分析 / 改名：左列控制是否参与画面抽帧，右列控制是否参与重命名；两列独立。
  • 文件 / 所在文件夹：点文件名用系统默认程序打开发现；下方小字是相对所选目录的子文件夹路径。
  • 设备（元数据）：文件内 ©too 记录的机型，读不到显示「— 未记录」。
  • 识别结果 / 来源 / 画面分析：原始色彩串、来源类型与行内分析结果；来源类型和状态以小字显示。
  • 标记为 / 改名后：可手动改的目标代码，以及对应的预览新文件名。

⑥ 画面分析

  • 勾选结果表「分析」列后点「分析选中画面」才抽帧，结果回填到对应行内，不会自动改名。
  • 饱和度 <32 → 较可能 D-Log M；>48 → 较可能普通 Rec.709；32~48 需肉眼确认。
  • 单次最多 100 个文件（「选未改名+未识别前100」会先清空旧勾选再按顺序选）。
  • 判据只标定过 D-Log M / Normal，对 D-Cinelike 无效：实测 O3 的 D-Cinelike 饱和度 26.9 会被误判成 D-Log M，请以 SRT 或人工指定为准。
  • 硬解默认开启：GPU 优先，显卡 / 驱动不支持时自动回退 CPU；取消勾选即走 CPU。只影响分析速度，不改变判定阈值，也不改动素材。

⑦ 批量与键盘提示

  • 改名范围：表头「改名」全选 +「所有已改名 / 未改名 / 未识别 / 已自定义」四个按钮。
  • 分析范围：全选 / 全选未识别 / 选前100 / 反选 / 清空；「已勾选分析文件标记为」可批量改标记，仅预览。
  • 按住 Shift 点「分析」列两个复选框，可连选区间。
  • 内置浏览器的路径输入框按 Enter 直接前往；Esc 依次关闭使用说明 → 更新日志 → 内置浏览器。

⑧ 常见问题

  • 字幕没写进文件？ 必须在录制前于 DJI Fly / 飞行眼镜开启「视频字幕」，事后补不了；已有素材只能手动指定或按画面参考。
  • 系统对话框卡住？ 点「取消系统对话框」，或直接用「浏览文件夹…」内置浏览器；系统弹窗 120 秒无响应会自动关闭并转到内置浏览器。
  • 画面分析提示缺 ffmpeg / Pillow？ 用 启动start.bat 启动（会选带依赖的解释器），或执行 pip install pillow imageio-ffmpeg；也可把 ffmpeg.exe 放进项目 bin/。
  • 换电脑怎么用？ 整个项目目录拷到任意路径即可（无需改代码）。用映射盘符双击 启动start.bat，不要用 UNC 路径；服务仅本机可访问。
